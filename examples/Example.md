# Example visual test

**Exe:** `path\to\Program.exe` — if an executable in backticks appears here, the window shows
its timestamp and can start it.

Check off: `[x]` = passes · `[!]` = finding · `[-]` = not tested.

---

## A. Start

- [ ] **A1 Program starts:** The main window appears without an error message; the title shows
      the version.
- [ ] **A2 Last state:** After a restart everything is as it was before closing.

## B. Operation

- [ ] **B1 Context menu:** Right-clicking an entry shows only what is possible there.
- [x] **B2 Already done:** A checkmark in the file is the starting state.
- [ ] An item without bold text gets a running identifier.
