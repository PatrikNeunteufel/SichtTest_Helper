# Beispiel-Sichttest

**Exe:** `pfad\zum\Programm.exe` — steht hier eine Exe in Backticks, zeigt das
Fenster ihren Zeitstempel und kann sie starten.

Abhaken: `[x]` = passt · `[!]` = Befund · `[-]` = nicht geprüft.

---

## A. Start

- [ ] **A1 Programm startet:** Das Hauptfenster erscheint ohne Fehlermeldung,
      der Titel nennt die Version.
- [ ] **A2 Letzter Stand:** Nach dem Neustart steht alles wie vor dem
      Beenden.

## B. Bedienung

- [ ] **B1 Kontextmenü:** Rechtsklick auf einen Eintrag zeigt nur, was dort
      geht.
- [x] **B2 Schon erledigt:** Ein Haken in der Datei gilt als Ausgangsstand.
- [ ] Ein Punkt ohne Fettdruck bekommt eine laufende Kennung.
